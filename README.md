# Controle de Homologação

Sistema completo para controle de homologação com backend FastAPI + PostgreSQL e frontend React (UX estilo SaaS).

## Subir tudo com Docker

```bash
docker compose up --build
```

## Endpoints e interfaces

- API: http://localhost:8000/docs
- Frontend: http://localhost:5173

## Funcionalidades

- Cadastro de homologações.
- Atualização de status inline.
- Filtros por status e cliente.
- Resumo consolidado com indicadores-chave.
